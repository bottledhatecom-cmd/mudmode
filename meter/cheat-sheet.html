mudmeter: cheat sheet

Measure first

  • Paste a chat into mudmeter to see its estimated tokens, the cost at your prices, and the parts that used the most.

Before you ask

  • Put several questions in one message instead of sending them one at a time.
    mudmode does the same back: its questions come in one numbered list. (free)
  • Paste only the part that matters, like the error line rather than the whole log.
  • Say the format you want: "3 bullets", "one line", "just the diff".
    mudmode keeps replies short and plain. (free)

While you work

  • Keep facts in a notes file and paste it in, so you don't explain again.
    mudmode does this for you: say "handoff" and paste the block it gives you into your next chat. (free)
  • Long thread? Ask for a 5-line summary, then start a new chat with it.
    mudmode does this for you: when a chat gets long, it offers a handoff block to start a fresh chat. (free)
  • If an answer goes wrong, fix your prompt and start again rather than adding "no, I meant…" over and over.

Pick the right size

  • Small or fast model: rewording, formatting, simple lookups, boilerplate.
  • Large model: hard reasoning, tricky bugs, long documents.

Set a budget

  • Set your own cap for the day or week, and check your usage page.
  • Hit a limit? Save a short summary (goal, done, next). Check when it resets. Use a smaller model for the simple parts. Then start a new chat with just the summary.
    mudmode does this for you: say "handoff". (free)
