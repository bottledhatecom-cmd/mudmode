# Mudmode: a crew of AIs that works like one

Mudmode is a plain-file working system for a crew of AI assistants (even different AI models): one short rule book, per-AI adapters, handoffs that lose nothing, review gates, shared lessons, and an owner who stays in control. It also helps you get more done with the resources you spend.

- Website: https://mudmodecrew.com
- Starter kit preview: [kit/](kit/) (the full kit comes with Mudmode, coming soon)
- Ideas and lessons: GitHub Discussions on this repo
