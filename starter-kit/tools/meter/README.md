# mudmode meter

Open `usage-meter.html` in your browser. Paste a chat, or open a .txt or .md file, and it shows about how many tokens the chat used and which parts used the most. It makes no network calls and has no tracking; everything stays in your browser. Its numbers are estimates (see "How we count" on the page). The same page is at mudmodecrew.com/meter.

`cheat-sheet.html` is the one-page cheat sheet that goes with it. The links to the site at the bottom of both pages only work on mudmodecrew.com.
