# cores: what `../MODULES-ON.md` says when mudgo is on (never edit these; edit `../CORE.md`)

Since v1.3.6 there is ONE core: `../CORE.md`. Part 1 is everyday and always on; Part 2 is mudgo (the `mudgo:` line in `../CORE-LOCAL.md`: auto, on or off). Nothing to swap, so no second core is needed.

- `MODULES-ON-PRO.md`: what `../MODULES-ON.md` says while mudgo is on (Part 2 holds every rule, so no module file loads).
- `CORE-LITE.md`, `CORE-FULL.md`, `MODULES-ON-FULL.md`: short pointers only, at the places where the old lite and full cores were; `../CORE.md` holds everything they said. Setup never deletes your own copies. Old words still work: "mudmode full" = mudgo on, "mudmode lite" = mudgo auto.

Switching steps: `../modules/README.md`. A switch never deletes anything.
