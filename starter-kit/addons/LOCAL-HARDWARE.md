# Add-on: LOCAL HARDWARE (optional)

**Optional; skip if you don't have a strong GPU.** mudmode works fully on any ordinary computer, including a laptop with no GPU, using cloud AIs only. This add-on is something you CAN turn on, never something you HAVE to.

> Got a strong PC? You can let mudmode use it. No strong PC? Everything still works.

## Before using anything here
1. **Check first.** The AI detects or asks what the owner has (CPU cores, memory, GPU and its memory, free disk, laptop on battery or not). It never guesses and never assumes a GPU.
2. **Offer, don't switch on.** The AI suggests a local option in one line, with the benefit, and waits for the owner's yes. Without a yes, stay on the generic default.
3. **Easy off switch.** Every local feature has one off switch the owner controls, and the off switch always wins.

## What you can turn on (only if your hardware fits)
- **Long jobs as scripts on your own computer:** test runs, screenshots, backups and link checks run as scripts instead of an AI waiting and reading output. Works on most computers; on a laptop, only while plugged in.
- **Keep the computer busy when idle:** a simple job queue that yields to the owner's own use (games, calls, big builds) and to real load.
- **A local AI model** (needs a strong GPU): first drafts and summaries only, each reviewed by a stronger AI; never code, rules, legal wording or release decisions.
- **Local image generation** (needs a strong GPU): art made on the owner's computer, with a cleared licence, each picture approved by the owner.
- **GPU sharing:** if several local jobs want the GPU, one runs at a time and the owner's own use comes first.

## Never
- Never make a local feature a requirement for the core kit.
- Never run heavy local jobs on battery, or while the owner is using the computer, without asking.
- Never install drivers or models, or change system settings, without the owner's OK (CORE rule 3).
