# mudmode module: lessons

**Adds:** the lessons book read at start (your areas only), a "Lessons for the crew" line on every report, and `DECISIONS.md` for settled lessons. Its rules replace the *everyday* lines in `CORE.md` (the same words are in `CORE.md` Part 2, mudgo).

16. Read the lessons book at start (when there is one); end every report with "Lessons for the crew" (one line or "none"); every lesson says how it is enforced. Cap the book at about 80 lines: when full, merge entries and move settled ones to `DECISIONS.md`.

**Files:** `LESSONS.md` (from `templates/LESSONS.md`; create it if missing), `DECISIONS.md` when the book is full.
**More:** the Full Kit book `full-kit/MUDMODE.md` §12.
