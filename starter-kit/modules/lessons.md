# mudmode module: lessons

**Adds:** the lessons book read at start (your areas only), a "Lessons for the crew" line on every report, and `DECISIONS.md` for settled lessons. Its rules replace the *lite* lines in `CORE.md`.

16. Read the lessons book at start; end every report with "Lessons for the crew" (one line or "none"); every lesson says how it is enforced. Cap the book at about 80 lines: when full, merge entries and move settled ones to `DECISIONS.md`.

**Files:** `LESSONS.md` (from `templates/LESSONS.md`; create it if missing), `DECISIONS.md` when the book is full.
