# Mudmode Starter Kit: preview

This folder is a **preview** of the Mudmode Starter Kit. The full kit (the complete one-page rule book, per-AI adapters and all templates) comes with Mudmode, **coming soon**.

Mudmode is a plain-file way to run one or more AI assistants as a steady crew: one short rule book, a lessons book that keeps getting better, clean handoffs between chats, review gates, and a "one OK = one action" rule for anything risky. It is tool-neutral: the rules live in plain Markdown files, and each AI gets a small adapter that points at them.

## What the full kit includes
- **CORE**: the full rule book, 25 rules on one page, read at every start
- **Adapters**: small per-AI files that point each AI at the same rules
- **Templates**: handoff, lessons book, progress file, job list, OK ledger, project add-on
- **Privacy checklist**: run before you share anything

## In this preview
- [SAMPLE.md](SAMPLE.md): 6 of the 25 CORE rules (summarized) and one template skeleton.
