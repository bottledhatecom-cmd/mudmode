Never done this before? Start here.

Click-by-click mudmode setup. About 15 minutes the first time, then two words a day.

This page is for you if you've never unzipped a file or used an AI "Project". No shame; everybody starts here. Do one numbered step, then the next. Words in bold are the exact things to click or type.

Jump to: What you need · 1. Get the file · 2. Unzip it · 3. ChatGPT · Claude · Grok · 4. Every day · 5. Stuck?

What you need

  • A computer (Windows or Mac) with a web browser. A phone works, but a computer is much easier.
  • Your mudmode download: the Full Kit, Founding 100 or the free starter kit. They all set up the same way.
  • An account on one AI app, the one you already use:
    • ChatGPT (chatgpt.com): Projects work on the free plan; free plans can add up to 5 files per project, and mudmode needs 1.
    • Claude (claude.ai): Projects work on the free plan (up to 5 projects).
    • Grok (grok.com): check your plan. Use the grok.com website; other Grok addresses may not have Projects.

1. Get the file

  1. Open your email. Search for Gumroad or mudmode.
  2. Open the email from Gumroad about mudmode.
  3. Click View content.
  4. If it asks for your email, type the one you bought with and press Enter.
  5. Click the Download button next to the mudmode file.

The file lands in your Downloads folder. Its name starts with mudmode and ends in .zip. No email? Check spam, or make a free Gumroad account with the same email and open your Library.

2. Unzip it

A .zip file is a folder squashed into one file for the trip. Unzipping un-squashes it.

On Windows

  1. Open File Explorer (the yellow folder icon on the taskbar).
  2. Click Downloads on the left.
  3. Find the mudmode file (it may have a little zipper on its icon).
  4. Right-click it and click Extract All...
  5. In the small window, click Extract.
  6. A normal folder opens. If there's just one folder inside, double-click it.

On a Mac

  1. Click Finder (the blue smiley face) in the Dock.
  2. Click Downloads on the left.
  3. Find the mudmode file ending in .zip.
  4. Double-click it. A normal folder appears right next to it.

Inside the folder is a folder called FOR-CHAT-APPS, and inside that, one file: mudmode-chat-setup.md. That's the only file your AI app needs. You don't have to open it.

3. Set up mudmode in your AI app

Pick one app and follow only its part. The sentence you'll type is the same everywhere: Read mudmode-chat-setup.md and set me up.

The pictures below are drawings, not real screenshots, so your screen may look a bit different. mudmode-chat-setup.md gives your AI all of mudmode's rules. Want the smaller lite mode instead? Use mudmode-chat-lite.md from the same folder and type Read mudmode-chat-lite.md and set me up.

ChatGPT

Prefer to watch? Short video of the ChatGPT steps (no sound):

  1. Go to chatgpt.com and sign in.
  2. In the left sidebar, click New project.
  3. Name it mudmode, pick any icon and color, and create it.
  4. In the project's sources area, click Add sources (or drag the file onto the project page).
  5. Open FOR-CHAT-APPS, click mudmode-chat-setup.md, then Open.
  6. Click the project's message box and type Read mudmode-chat-setup.md and set me up. Press Enter.
  7. Answer its short questions, or just type defaults.
  8. Click Copy on the block titled "Paste this into your project instructions".
  9. On the project page, click •••, then Project settings.
  10. Paste the block into the instructions box (replace what's there) and click Save.

Claude

Prefer to watch? Short video of the Claude steps (no sound):

  1. Go to claude.ai and sign in.
  2. On the left, click Projects (or go to claude.ai/projects).
  3. Click + New Project (top right).
  4. Name it mudmode and create it.
  5. In the project knowledge area on the right, click + and upload a file.
  6. Open FOR-CHAT-APPS, click mudmode-chat-setup.md, then Open.
  7. In the project's message box, type Read mudmode-chat-setup.md and set me up. Press Enter.
  8. Answer its short questions, or type defaults, then click Copy on the block it gives you.
  9. Back on the project page, click Set project instructions.
  10. Paste the block and click Save instructions.

Grok

Prefer to watch? Short video of the Grok steps (no sound):

  1. Go to grok.com and sign in.
  2. In the left sidebar, click Projects.
  3. Make a new project named mudmode.
  4. Add the file mudmode-chat-setup.md from FOR-CHAT-APPS to the project.
  5. Start a chat in the project and type Read mudmode-chat-setup.md and set me up. Press Enter.
  6. Answer its short questions, or type defaults, then copy the block it gives you.
  7. Open the project's Instructions, paste the block and save.

4. Every day after that

  1. Open your mudmode project and start a new chat. Work like normal.
  2. Before you stop, type handoff.
  3. Click Copy on the HANDOFF block it gives you.
  4. Next time, start a new chat in the project and paste that block as your first message.

Any time: type mudmode status for what's done, what's next and what needs you.

5. Stuck?

Can't find the downloaded file? Look in Downloads. Still nothing? Click View content in your Gumroad email again; downloading twice is fine.

No Projects option? Use the website on a computer, signed in. Some plans don't have Projects; check your plan. You can also use the attach way below in a normal chat.

The AI says it can't read the file? Click the + or paperclip next to the message box, attach mudmode-chat-setup.md, and type Read mudmode-chat-setup.md and set me up. again.

Forgot to say handoff? Open that chat again and type handoff now.

Chat got long and slow? Type handoff, start a new chat in the project, paste the block.

Want to change your name or settings? Type change my mudmode settings.

Still stuck? Tell us which step you're on and what you see: contact details.

Optional: Claude Code (if you're comfortable)
