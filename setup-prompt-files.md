# mudmode quick setup (for Claude Code or another AI that works with files)

AI: please set up the free mudmode Crew kit for me, quietly. Keep your own messages to me short and plain, one line per step, like "Getting the kit...", "Checking it's the real file...", "Setting it up...", "Cleaning up...". You don't need to explain the commands. Run each step as its own command from this page, never a script file you wrote yourself, so my AI app can show me each one before it runs. If I ask what you ran, show me exactly. If anything fails or looks different from what this page says, stop and tell me in one plain line. Where the kit's README.md or setup/AI-SETUP.md say something different, this page wins; still follow their ground rules, except that step 2 is the one download.

1. Ask me only this, then wait: "I'll put mudmode, a few plain text rule files, in a mudmode folder in your home folder, and connect it so every new chat in this AI follows it, in any project on this computer. Nothing else on your computer changes. OK? (yes / yes, but don't connect it / use another folder / no)". If I say no, stop. If a mudmode folder is already there, say so in the same message (setup keeps my files and backs up anything it updates). Another folder must be new or empty: never my home folder itself, a whole drive, or a folder with other files in it. If the folder I name isn't allowed, say why and ask once for another.
2. Make one new empty folder inside this computer's temp folder and download https://mudmodecrew.com/starter-kit/mudmode-starter-kit.zip into it. Go on only if its SHA-256 passes:
   - bash: `echo "ac8833cac27b3baa084e89fde2831a6934d4777e46b8f54a3b6ccca7887f65b8  mudmode-starter-kit.zip" | sha256sum -c` prints `mudmode-starter-kit.zip: OK` (macOS: `shasum -a 256 -c` instead of `sha256sum -c`)
   - PowerShell: `(Get-FileHash mudmode-starter-kit.zip -Algorithm SHA256).Hash -eq 'AC8833CAC27B3BAA084E89FDE2831A6934D4777E46B8F54A3B6CCCA7887F65B8'` prints `True`
   If it fails, delete that one file, tell me "The download didn't match, so I stopped. Copy a fresh prompt from mudmodecrew.com and try again.", and stop.
3. Unzip it there, read README.md, setup/AI-SETUP.md and the setup script, then run AI-SETUP.md step 2's command (bash or PowerShell, whichever works here) with: `--yes`; `--connect claude` only if you are Claude Code and I said yes (`--connect grok` for Grok Build; otherwise `--connect none`); my time zone as a name like `America/Chicago`, from this computer's settings; my folder if I named one (`--target`). PowerShell uses -Yes, -Connect, -Tz, -Target. Everything else stays at its default. Write only in the new mudmode folder, plus the one connector file I said yes to; delete nothing of mine; nothing else online.
4. When the script prints `RESULT: OK`, delete only the temp folder from step 2: one command, its full path in quotes, no variables or wildcards. If you're not sure of the path, or you stopped early, leave it and tell me where it is.
5. Tell me I'm done in 4 short lines. First line: "Woot! mudmode is set up." Then:
   - where the folder is;
   - if connected: "Start a new chat and it follows mudmode. Say handoff before you stop, and mudmode status any time." If not connected: "To use it, start a chat with: Read the CORE.md, CORE-LOCAL.md and HANDOFF.md files in my mudmode folder, then continue. Say handoff before you stop."
   - "Say change my mudmode settings to change your name or time zone (I guessed <zone>), or to turn on update notices."
   If I ask how to undo it, tell me, and don't delete anything unless I say so: to turn it off, delete the connector file; to remove it all, delete the mudmode folder (only ones setup made new).
