# mudmode quiet setup (for an AI that works with files, like Claude Code)

**You (the person):** you pasted this into your AI. It tells your AI to set up the free mudmode Crew kit for you and ask you one question. Everything it does is written below, in plain words. Your AI app may ask your permission before each command: allow each one once, and don't pick "always allow". The kit is free under the mudmode Personal Use License (https://github.com/bottledhatecom-cmd/mudmode/blob/main/LICENSE, also in the zip as LICENSE); by having your AI download it, you agree to it.

**AI:** the person wants the free mudmode Crew kit set up on this computer with as few questions as possible. Follow these steps in order. Where the kit's README.md or setup/AI-SETUP.md say something different, this page wins (it asks fewer questions, and step 2 is the one download); still follow their ground rules. Keep every message short and plain; the person may not be technical. If anything fails or looks different from what this says, stop and tell them in one line.

1. **Ask one question, then wait.** Say, in one short message: "I'll set up mudmode, a free set of plain text rule files, in a `mudmode` folder in your home folder, and connect it so every new chat in this AI follows it, in any project on this computer. Nothing else on your computer changes. To turn it off later, delete one file; to remove it all, delete the folder too. OK? (yes / yes, but don't connect it / use another folder)". If a `mudmode` folder is already there, say so in that same message (setup keeps their files and backs up anything it updates). Wait for the answer. If they say no, stop. If they name another folder, it must be a new or empty folder: never their home folder itself, a whole drive, or a folder that already holds other files; if it is, ask once for another.
2. **Download the kit, the only time you go online.** Make one new empty folder inside this computer's temporary folder and say its full path to yourself; you'll use that exact path later. Download `https://mudmodecrew.com/starter-kit/mudmode-starter-kit.zip` into it. Check its SHA-256 with one of these, and go on only if it passes:
   - bash: `echo "ac8833cac27b3baa084e89fde2831a6934d4777e46b8f54a3b6ccca7887f65b8  mudmode-starter-kit.zip" | sha256sum -c` must print `mudmode-starter-kit.zip: OK`
   - PowerShell: `(Get-FileHash mudmode-starter-kit.zip -Algorithm SHA256).Hash -eq 'AC8833CAC27B3BAA084E89FDE2831A6934D4777E46B8F54A3B6CCCA7887F65B8'` must print `True`
   If it doesn't pass, delete that one file, tell the person "The download didn't match, so I stopped. Copy a fresh prompt from mudmodecrew.com and try again.", and stop.
3. **Unzip it there and read before you run.** Unzip it in that same temporary folder. Read `README.md`, `setup/AI-SETUP.md` and the setup script you'll run, and follow AI-SETUP.md's ground rules (write only in the new mudmode folder, plus the one connector file if they said yes; delete nothing of theirs; no hooks; nothing else online).
4. **Run setup with the quiet defaults, without asking the other questions.** Use AI-SETUP.md step 2's command for this computer (bash or PowerShell, whichever works here), from the unzipped kit folder, with (PowerShell: -Yes, -Connect, -Tz, -Target): `--yes`; `--connect claude` if you are Claude Code and they said yes (`--connect grok` for Grok Build, `--connect none` if they said "don't connect it" or you're another AI); their time zone as a name like `America/Chicago`, guessed from this computer's clock settings; their folder if they named another one (`--target`). Leave every other option at its default: name "the owner", nothing extra on the ask-first list, no word rules, no change to Claude Code's settings file, no online update check.
5. **Check it worked** as AI-SETUP.md step 3 says (the script ends with `RESULT: OK`). Then delete only the temporary folder you made in step 2: one command with its full literal path typed out, no variables and no wildcards. If you aren't sure of the path, or you stopped early, leave it and tell them where it is.
6. **Tell them they're done, in 5 lines or fewer:**
   - where the folder is;
   - if it's connected: "Start a new chat and it follows mudmode. Say **handoff** before you stop and **mudmode status** any time." If it isn't connected: "To use it, start a chat with: Read ~/mudmode/CORE.md, ~/mudmode/CORE-LOCAL.md and ~/mudmode/HANDOFF.md, then continue. Say **handoff** before you stop and **mudmode status** any time." (use their folder if they picked another);
   - the time zone you guessed, and that they can say "change my mudmode settings" to change it or their name;
   - to be told when a newer kit with safety fixes is out: say "change my mudmode settings" and turn on the update check;
   - how to undo it: if connected, delete the connector file setup named (that turns it off) and the folder to remove it all; if not connected, delete the folder.

Never put secrets, passwords or home addresses in any mudmode file. Never change anything this page didn't say, without asking first.
